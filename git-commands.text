=====

Create new branch:

git status

git fetch origin &&
git switch -c evidence_factory_fix origin/develop &&
git push -u origin evidence_factory_fix

=====

commit and Push

git branch --show-current
git status
git add .
git diff --cached --stat
git commit -m "Fix evidence factory issues"
git push -u origin evidence_factory_fix

=====

Reset and hard pull:

git fetch origin &&
git reset --hard origin/develop

git clean -nd

git clean -fd
